## 使用方法

前序运行曾使用个人目录脚本启动；该方式已被本轮仓库入口替代：

```bash
python3 ~/.codex/skills/local-ai-mvp-builder/scripts/run-supervised.py \
  --project "/项目绝对路径" \
  --plan "/计划绝对路径.md" \
  --model primary
```

需要在终端查看详细事件时增加：

```bash
--display live
```

用户验收后，可以明确要求“上传 GitHub”；此时才进入提交、推送分支和创建 PR 的流程。

### 使用方法

先在不写文件的模式查看全部目标：

```sh
./bin/install-agent-skills --dry-run
```

确认后安装，并保证用户命令目录在 PATH 中：

```sh
./bin/install-agent-skills
export PATH="$HOME/.local/bin:$PATH"
```

执行批准计划：

```sh
mvp-loop-supervised \
  --project "/项目绝对路径" \
  --plan "$HOME/.local/share/local-ai-mvp-builder/plans/项目-plan.md" \
  --model primary \
  --display summary
```

普通冲突先人工核对；确需替换时使用 `--force`，并保留安装器生成的时间戳备份用于恢复。
