## 使用方法

批准计划后，从任意受支持前端调用 `$local-ai-mvp-builder`，或运行：

```sh
mvp-loop-supervised \
  --project "/absolute/path/to/project" \
  --plan "/absolute/path/to/approved-plan.md" \
  --model primary \
  --display summary
```

只有外部运行目录中 `summary.json.status` 为 `ready_for_user_review` 才能交付；`needs_manual_attention` 必须按 failure classification 继续修复或恢复环境后重试。
