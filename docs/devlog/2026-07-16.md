## 使用方法

默认使用 OpenCode 主方案：

```sh
mvp-loop-supervised \
  --project "/absolute/path/to/project" \
  --plan "/absolute/path/to/approved-plan.md" \
  --model primary \
  --local-backend opencode \
  --display summary
```

仅在明确诊断或兼容需求下选择 `--local-backend codex-ollama`。需要观察运行过程时使用 `--display live`；界面只显示脱敏事件与模型提供的摘要，不展示或保存原始私有思维链。
