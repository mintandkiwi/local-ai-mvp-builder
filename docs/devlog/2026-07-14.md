## 使用方法

继续通过统一入口执行已批准计划：

```sh
mvp-loop-supervised \
  --project "/项目绝对路径" \
  --plan "/计划绝对路径.md" \
  --model primary \
  --display summary
```

计划正文必须包含恰好一条真实风险声明，例如 `Risk classification: low`。运行结束后重点检查 `summary.json` 的 `status`、`review`、`usage.stages`、`workflow.takeover` 和 `efficiency.claim`；只有验证与独立终审均通过时才能交付用户评审。
