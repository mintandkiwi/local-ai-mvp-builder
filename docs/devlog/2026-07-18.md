- 将批准计划、capsule 与去敏验证证据作为运行目录的只读输入开放给 OpenCode fixer；整次运行固定启动日，跨午夜不会改变开发日志的 allowlist 或回写范围。

## 使用方法

继续使用 OpenCode 主后端：

```sh
mvp-loop-supervised \
  --project "/absolute/path/to/project" \
  --plan "/absolute/path/to/approved-plan.md" \
  --model primary \
  --local-backend opencode \
  --display summary
```

需要诊断本地执行过程时，使用 `--display live`。界面仅显示脱敏事件、工具摘要、步骤 Token 和顶层错误，不输出原始私有思维链。
