## 验收标准

- 本地模型正常时，完成代码、测试和三份中文文档后才允许 Review 通过。
- 本地模型失败或 300 秒无结构化进展时，Codex 自动接管，不要求用户重新启动流程。
- Codex 对话不复制本地模型运行细节，只报告关键阶段和异常。
- `summary.json` 包含最终状态、验证、Git diff 和安全版本快照。
- 未得到用户授权时不存在自动 commit、push、tag 或 GitHub 仓库创建行为。
